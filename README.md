# Générateur SQL

Projet réalisé en Java dans le cadre de mon bachelier en programmation.

L'objectif du projet est de générer automatiquement des données SQL à partir d'un fichier créé avec JMerise.

Le programme analyse les tables et leurs attributs afin de générer des instructions `INSERT INTO` avec des données adaptées.

## Fonctionnalités

- Lecture d'un fichier JMerise
- Récupération des tables et de leurs attributs
- Identification des clés primaires et étrangères
- Reconnaissance des différents types de données
- Génération automatique de requêtes `INSERT INTO`
- Génération de données fictives avec JavaFaker
- Création d'un fichier SQL contenant les données générées

## Technologies utilisées

- Java
- JMerise
- JavaFaker
- SQL
- IntelliJ IDEA

## Pourquoi ce projet ?

Ce projet m'a permis de travailler la manipulation de fichiers en Java, la génération de données et de mieux comprendre la structure d'une base de données relationnelle.

Il m'a également permis de mettre en pratique plusieurs notions vues pendant mon bachelier.
